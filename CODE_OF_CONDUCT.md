# Code of Conduct

We want bdkit to be a welcoming place for everyone, regardless of experience, background or identity.

- Be respectful and patient, especially with first-time contributors.
- Critique code, not people.
- No harassment, insults, or discriminatory language.

If something goes wrong, contact the maintainer by opening a private issue or emailing the address on the maintainer's GitHub profile. The maintainer may remove comments or block users who don't follow these guidelines.
